# Baked Live for Android

**Created by keatingfish.**

**Baked Live v1.10** is a Baked.live room viewer for **Android phones, Android tablets, Android TV, and Google TV**.

> **Platforms:** The Baked Live app installs on Android phones, tablets, and TVs only. There is no Windows, macOS, or desktop app. A computer's web browser can be used for the casting and chat companion features described below.

**[Download Baked Live v1.10 APK from GitHub](https://github.com/buttocks/bakednetwork/releases/download/v1.10/baked-live-1.10.apk)** · [Release notes and checksum](https://github.com/buttocks/bakednetwork/releases/tag/v1.10)

Sign in using your [baked.live](https://baked.live) account. New accounts must be registered at baked.live in a web browser.

## Install on a phone or tablet

1. Download the [APK](https://github.com/buttocks/bakednetwork/releases/download/v1.10/baked-live-1.10.apk) on your Android phone or tablet.
2. Open the downloaded file.
3. If Android blocks the install, open the prompted **Settings** page, enable **Allow from this source** for the browser or file manager you used, then return.
   - Manual path on many devices: **Settings > Apps > Special app access > Install unknown apps**, then choose your browser or Files app.
   - Samsung: **Settings > Apps > ⋮ > Special access > Install unknown apps**.
4. Tap **Install**, then open **Baked Live** and sign in.
5. If Play Protect displays a warning, review it before deciding whether to continue. Only install APKs from a source you trust.

No Android developer options are required. After installing, you can turn off **Allow from this source** again if you prefer.

## Install on Android TV or Google TV

1. Install the **Downloader** app on the TV.
2. Allow Downloader to install apps under **Settings > Apps > Security & restrictions > Unknown sources**. On some devices this is under **Device Preferences > Security & restrictions**, or **Special app access > Install unknown apps**.
3. Open Downloader and enter:
   
   `https://github.com/buttocks/bakednetwork/releases/download/v1.10/baked-live-1.10.apk`
4. Select **Go**, install the APK, then open Baked Live and sign in.

Developer options are not required.

## Updating

Download the latest APK and install it over your existing copy. Normally you stay signed in and keep your settings; there is no need to uninstall first.

If Android reports a conflicting package signature, the installed version may have come from a different source. You may need to uninstall it and reinstall the new APK, then sign in again. Uninstalling may clear app data.

## TV remote controls

| Button | Action |
| --- | --- |
| **Right** | Open **Now Playing**, listing rooms and their current videos; choose one to switch rooms |
| **Left** | Open the current room's schedule |
| **OK** | Open the bottom control bar (Pause, Cast, Settings); OK again pauses. If already paused, first OK plays |
| **Left / Right while control bar is open** | Move between Pause, Cast, and Settings |
| **Up / Down** | No action in the room, preventing accidental navigation |
| **Channel Up / Down** | Change rooms, if your remote has those buttons |
| **Back** | Close the open panel, then return to the rooms list |
| **Menu** | Open Settings, if available |
| **Hold OK on room list** | Add a room to favorites (up to four), or remove a favorite |

## Cast and chat

On an **Android phone or tablet**, tap **Cast**. You can discover TVs running Baked Live on the same Wi-Fi network. You can also choose **Watch on computer** or **Chat on computer**. Computers participate through a **web browser only**; there is no desktop APK or app.

These connections require your devices to be on the same local Wi-Fi network.

### Cast from phone or tablet to TV

Watch video on the TV while keeping chat on your phone or tablet.

1. Open Baked Live on the TV. It does not need to be signed in.
2. On your phone or tablet, tap **Cast** and choose the TV showing **Cast here**.
3. Enter the TV's four-digit pairing code the first time.

If the TV does not appear, verify that Baked Live is open on it and both devices are on the same Wi-Fi.

### Watch on computer

Play video in your computer's browser while using chat on the Android phone or tablet.

1. On your phone or tablet, choose **Cast > Watch on computer**.
2. On the computer, enter the address shown on your phone into its browser.
3. Click **Start watching**. Press **F** for fullscreen.

### Chat on computer

Keep video on your Android phone or tablet and type into chat using a computer keyboard.

1. On the phone or tablet, choose **Cast > Chat on computer**.
2. Open the displayed address in the computer's browser and enter the pairing code.

### Chat through a TV

Use an Android phone, tablet, or a computer browser to type in the chat for a **signed-in TV that is playing a room**.

1. On the TV, press **OK**, select **Cast**, and note the address and code.
2. On an Android phone or tablet that is not signed in, open Baked Live, select **Use a TV on this Wi-Fi**, choose the TV marked **Chat through this TV**, and enter the code.
3. Alternatively, on a computer open the TV's displayed address in your browser and enter the code.

### Stop casting

- **Phone:** Tap **Stop casting** at the top of the chat screen.
- **Tablet:** Open **Casting controls > Cast > Stop casting**.
- **Notification:** Tap **Stop** in the **Casting to ...** notification.

### Casting with the phone/tablet screen off

During a cast, the **Casting to ...** notification helps keep the session running when the Android screen turns off. Allow Baked Live notifications when prompted so the status can appear.

If the connection drops, reopening Baked Live can resume the existing cast without another code.
