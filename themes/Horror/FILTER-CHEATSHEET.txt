HORROR TUBE — CHAT FILTER CHEAT SHEET
These filters only work after an admin imports filters.json.
Use the navbar's ☾ HORROR EFFECTS dropdown to insert any trigger.

== TEXT EFFECTS ==
[hwhisper]...[/hwhisper]              WHISPER — Subtle whispering text
[hglitch]...[/hglitch]                GLITCH — Unsettling glitch-styled text
[hblood]...[/hblood]                  BLOOD LETTERS — A blood-red message
[hstatic]...[/hstatic]                STATIC — TV static lettering
[hspoiler]...[/hspoiler]              HIDDEN SPOILER — Blurred text that reveals on hover/focus
[hnight]...[/hnight]                  NIGHT VISION — Green night-vision message

Example: [hglitch]IT'S BEHIND YOU[/hglitch]
Example: [hspoiler]The killer is revealed[/hspoiler]

Do not import the 153-rule WrestleTube source directly: it contains wrestling,
personalized, and broad spam rules. Horror filters.json contains the clean selection.
