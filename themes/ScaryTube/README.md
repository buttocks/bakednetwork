# ScaryTube v1.0 — After Dark

Standalone Baked.live channel theme based on the previously working Horror Tube v1.0 package. The old Horror Tube and WrestleTube files remain unchanged.

## Links

- External JavaScript: `https://cdn.jsdelivr.net/gh/buttocks/bakednetwork@main/themes/ScaryTube/skin.js`
- External CSS: `https://cdn.jsdelivr.net/gh/buttocks/bakednetwork@main/themes/ScaryTube/skin.css`
- Complete chat filters: [filters.json](https://raw.githubusercontent.com/buttocks/bakednetwork/main/themes/ScaryTube/filters.json)

## Features

Proven WrestleTube/Xaekai module loader, original player and playlist controls, and **Layout → Cinema Mode**; black-and-crimson theater design, ScaryTube branding, an interactive **☾ SCARY EFFECTS ▾** menu for 26 stamps and 6 text effects, and an optional MOTD. Includes 88 neutral original rules plus 32 horror effects (120 total); no wrestling-specific chat rules and no new emotes.

## New channel wiring

Set the two hosted external URLs, replace the fresh channel's chat filters with `filters.json`, and optionally use `channel-motd.html` as the MOTD. Do not also load the old WrestleTube internal JS. The signature filter is now `:scarytube:` instead of `:horrortube:`.

Source/syntax checked; live Baked.live testing is still pending. No live channel was changed.
