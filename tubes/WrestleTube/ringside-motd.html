Chat Tools

Welcome. This guide will help you understand the advanced features available to this chat.


Global Keyboard Shortcuts:

  • ALT W: Toggle Cinema Mode
  • ALT S: Toggle image spoiler type between click and hover

Chatline Keyboard Shortcuts:

These codes only work when you have the chatline in focus. Excessive use/stacking of image effects will lead to moderation action. During official stream events, some features may be disabled.

  • CTRL B: Bold Text
  • CTRL I: Italic Text
  • CTRL ~: Strike through
  • CTRL P: Appends .pic (to embed images)
  • CTRL S: Spoiler (text only)
  • CTRL M: Mirror emotes/images
  • CTRL F: Flip emotes/images
  • CTRL /: Tilt emotes forward
  • CTRL \: Tilt emotes backward
  • CTRL SHIFT V: Paste image URL + embed code
  • CTRL SHIFT B: Blur an emote/image
  • CTRL SHIFT S: Shake an emote/image

Animation Effects

There are several chat filters for various types of scrolling. Add them in the chatline. Abuses of these features will also lead to moderation action.

  • Spin me, right round baby!
    • Add [spin][/spin] around your message to make it spin clockwise

  • The wrestling says marquee!
    • Add [marquee][/marquee] to move your message from the right side of the screen to the left

  • Bounce!
    • Add [bounce][/bouncee] to move your message from the right side of the screen to the left and then bounce back

  • Speed (or "The Macro That Never Stopped")

    • You can use :fast, :faster and :fastest modifiers to adjust the speed of the above effects

    • [spin:fast][/spin] will make your message spin fast
    • [marquee:faster][/marquee] will make your message move faster
    • [bounce:faster][/bounce] will make your message bounce the fastest

  • Change direction!

    • You can use :reverse to change the direction of the above effects

    • [spin:reverse][/spin] will make your message spin counter-clockwise
    • [marquee:reverse][/marquee] will make your message move left to right
    • [bounce:reverse][/bounce] will make your message bounce left to right

  • Combining modifiers

    • You can combine direction and speed modifiers by adding a space between, for example:

    • [spin:reverse fast][/spin] will make your message spin counter-clockwise fast
    • [marquee:faster reverse][/marquee] will make your message move left to right faster

  • Combining animations

    • Now you're shitposting with portals...

    • [marquee:fastest reverse][spin:fast][/spin][/marquee] will semd a message really fast spinning across the screen

Special filters

Other Effects

Some other chat filters for various functions listed in this section. Add them in the chatline. Abuses of these features will also lead to moderation action.

  • Add :center: center text/emote in the chat
  • Add :butt0n: to add a button around your text/emote
  • Add :comic: to make your message have comic sans font
  • Add :flames: to add flames to your message or emote/image
  • Add :sparkle: to add sparkles your message or emote/image
  • Add :right: to make your message or emote/image align to the right side of chat
  • Add :spread: to space your text out

Chatline Slash commands

  • /selfclear: This will wipe the chat only for you. Use this if someone embeds something you don't like.
  • /sclear: Shortcut for above.
  • /spoiler: Toggle image spoiler type between click and hover
  • /wipesettings: This will wipe all your channel settings
  • /setcolor: This accesses the color system settings
    • /setcolor type [static|cycle|random]
      • Example /setcolor type static
    • /setcolor static #RGBHEX
      • Example /setcolor static #CC66FF
    • /setcolor cycle ["#RGBHEX","HTMLColorCode"]
      • Example /setcolor cycle ["orange","yellow","lime","#00FFFF"]
    • Both 3 and 6 character hex codes are accepted.
  • /pm %user%[ msg]: Send a private message to a user without having to open the PM bar
    • Example: /pm nuclearace Quit being so god damn lazy.
  • /tts: Toggle the text-to-speech engine.

Media embedding

There are several embedding codes for various media. You append these codes to the end of the URL. Abuses of these features will lead to moderation action.

  • Add .pic for standard image embedding
  • Add .spl to embed an image spoilered
  • Add .vid to embed webms or mp4s
    • You can append additional flags:
      • a: autoplay
      • m: unmuted
      • l: loop
      • c: hidden controls
    • For example .vidalc to emulate a gif. Only moderators can use a and m together.
  • Add .embed for Imgur gifv links
  • Add .play for wav/ogg/mp3
  • If someone has embedded one of these, you can CTRL click it to fetch the URL into the chatline.

    *You may need to add a space after the message you'd like add an effect to.
