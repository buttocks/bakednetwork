# Shared wrestling base

Derived from the established WrestleTube selfhost-v1 channel-internal.js; original attribution retained. Existing sequenced loader, module options, pinned module dependencies and active/inactive selections retained. Branding is supplied by each channel via BakedWrestlingBrand. Shared Playlist Tools added after existing modules for rank 2+. Pilot NWA-TNA before wider rollout; original WrestleTube files unchanged.

Module recovery: failed requests time out after 20 seconds and the sequence continues. The NWA-TNA pilot build is generated from the canonical base; live deployment requires a separate verified operation.
